# Securitybeleid

## Ondersteunde versies

Beveiligingscorrecties richten zich op de actuele publieke Aurora-release en de
actieve ontwikkelbranch.

## Kwetsbaarheid melden

Publiceer geen tokens, wachtwoorden, externe URL’s, camera-inhoud, `.storage`-
exports of volledige Home Assistant-configuraties in een openbaar issue.

Meld een mogelijk beveiligingsprobleem privé via GitHub Security Advisories van
de repository. Beschrijf impact, reproduceerstappen en betrokken Aurora-versie.

## Buiten scope

Problemen in Home Assistant, HACS-kaarten of apparaatfirmware moeten ook bij het
betreffende upstreamproject worden gemeld. Aurora bewaart zelf geen
inloggegevens en levert geen cloudservice.
