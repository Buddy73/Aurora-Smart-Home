# Aurora installatievoorbeelden

Deze map bevat uitsluitend veilige, installatie-onafhankelijke voorbeelden.

- `configuration.yaml` laadt het Aurora-theme en toont de optionele koppeling
  voor Utility Meter.

Kopieer nooit het volledige voorbeeld over een bestaande Home Assistant-
configuratie. Voeg alleen de benodigde sleutel toe en voorkom dubbele
top-level-sleutels.

Dashboardkaarten en entity-ID’s worden bewust niet als universeel voorbeeld
opgenomen: deze moeten aansluiten op de werkelijk aanwezige apparaten en
integraties.
