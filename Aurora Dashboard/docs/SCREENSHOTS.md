# Screenshots

Screenshots van de privé Home Assistant-installatie worden niet in de publieke repository opgenomen.

Dit voorkomt publicatie van:

- namen en profielfoto’s;
- woningstatus en live meetwaarden;
- camera-informatie;
- apparaatnamen en lokale indeling.

Gebruik voor publieke documentatie uitsluitend volledig geanonimiseerde demonstratiebeelden.
