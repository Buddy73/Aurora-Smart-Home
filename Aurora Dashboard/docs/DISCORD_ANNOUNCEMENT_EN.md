# Discord announcement — Aurora UI v1.1.0-rc.1

> **Aurora UI is a premium, modular interface for Home Assistant.**
>
> I am happy to share the first Release Candidate of **Aurora UI**: a
> Storage Mode dashboard designed to make daily Home Assistant control feel
> calmer, clearer and more personal.
>
> Aurora includes dedicated views for energy, climate, lighting, media,
> cameras and hobby/garage. It is designed for desktop, tablet and mobile, with
> a consistent Aurora visual language and a strong focus on readability and
> everyday usability.
>
> **Highlights**
>
> - Premium dark theme with subtle Aurora accents
> - Sections Layout, Mushroom Cards, Bubble Card, ApexCharts and card-mod
> - Modular structure: Theme, Dashboard, Components and Effects can be used
>   independently
> - Documentation for installation, usage, troubleshooting and contributing
> - Public demo mock-ups without personal Home Assistant data
>
> This is a **Release Candidate**. I am especially looking for feedback on
> installation, responsive behaviour, readability, and card or styling issues.
>
> **Transparency:** Aurora was developed collaboratively by its maintainer and
> OpenAI Codex/ChatGPT. The dashboard decisions and live behaviour were
> reviewed and validated in a real Home Assistant installation.
>
> GitHub: https://github.com/Buddy73/Aurora-Smart-Home
